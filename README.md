# mvassa

Prototype de site touristique immersif pour Mvassa Le Rocher.

- `index.html` : version vidéo, la visite guidée Matterport rejouée au scroll (images dans `seq/`).
- `index-photos.html` : première version, 6 points de vue en photos (images dans `img/`).

Pour le voir en local :

```bash
python3 -m http.server 8800
```

puis ouvrir http://localhost:8800.
